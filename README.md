# Pokédex Ultra Premium

Dự án nghiên cứu **GraphQL + Next**

---

### 🚀 Stack

- **React 19 / Next.js 16**: (Static Export Mode)
- **Apollo Client**: Kết nối trực tiếp với PokeAPI GraphQL.
- **Tailwind CSS**: Thiết kế hiện đại (Glassmorphism).

### 🛠 Cài đặt & Chạy

```bash
npm install
npm run dev
```
